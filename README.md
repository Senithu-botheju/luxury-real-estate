# Zillopia | Luxury Real Estate Agency in Dubai

A premium luxury real estate website showcasing exclusive properties in Dubai's most prestigious locations.

## 🏢 Overview

Zillopia is a bespoke real estate portal specializing in off-market luxury properties in Dubai. The site features:
- Exclusive property listings with high-quality imagery
- Location-based property discovery (Palm Jumeirah, Downtown Dubai, Emirates Hills)
- Advanced filtering system (price range, property type, location)
- Private concierge booking system
- Professional brand positioning for luxury market

## 🎨 Design Features

- **Luxury Aesthetic**: Premium design with gold accents, generous whitespace
- **Micro-Interactions**: Smooth hover effects, button feedback, elegant transitions
- **Scroll Animations**: Content fades in and slides up as users scroll
- **Fully Responsive**: Optimized for desktop (1440px), tablet (768px), mobile (375px)
- **High Performance**: Lighthouse score 90+, fast load times via Vercel CDN

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Modern CSS with responsive design
- **Deployment**: Vercel (auto-scaling, global CDN)
- **Hosting**: Vercel Edge Network (99.99% uptime)
